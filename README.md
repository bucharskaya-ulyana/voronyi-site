# Кольористика в поезії Миколи Вороного

Сайт до випускної роботи. Зроблений на чистому HTML, CSS та трохи JavaScript —
без бібліотек і без збирання, тому відкривається будь-де.

## Як відкрити

**У WebStorm:** File → Open → вибрати папку `voronyi-site`.
Потім відкрити `index.html` і натиснути на значок браузера у правому верхньому куті редактора.

**Без WebStorm:** просто двічі клацнути на `index.html`.

## Що де лежить

```
voronyi-site/
├── index.html        1. Вступ та історія кольору
├── kolory.html       2. Історія назв кольорів (2.1) + кольори, що відкриваються
├── biografiia.html   3. Творчий доробок, біографія (2.2.1)
├── zasoby.html       4. Особливості колірних художніх засобів (теорія)
├── virshi.html       5. Вірші, веселка-діаграма, гра «Вгадай колір»
├── vysnovok.html     6. Висновок і джерела
├── css/style.css     усі стилі (кольори, шрифти, розмітка)
├── js/script.js      меню, картки кольорів, веселка, гра
└── images/           картинки (SVG — малюнки, зроблені кодом; портрет voronyi.jpg додати)
```

## Шрифти

Шрифти підключаються з Google Fonts, тому для красивого вигляду потрібен інтернет.
Без інтернету сайт теж працює, просто зі стандартними шрифтами.
